# Statistics for Data Science

A complete study guide that covers statistics for data science, following the analytics pipeline:

**Data -> Descriptive -> Diagnostic -> Predictive -> Prescriptive -> Action**

## About

These notes astatistics_data_science_course **"Statistic for Data Science"** by **Ahmad Alamm**.

Course playlist: https://www.youtube.com/playlist?list=PLO3fADoO5fwNTr4Zjmz-cacmMh1S0o4Ml

I organized the notes into one file, added new examples, and filled in missing topics. All credit for the original content goes to the instructor. This is an independent study companion, not an official copy of the course.

## What's inside

- Data types and sampling
- Descriptive statistics
- Probability and Bayes' theorem
- Hypothesis testing and correlation
- Regression, forecasting and classification
- Expected value and decision making
- Formula sheet and glossary
